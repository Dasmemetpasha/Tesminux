Tesminux

An Android terminal tool written in Rust — a "vibe coding" project.

Tesminux is an experimental Android terminal tool built with Rust.

The goal is simple: create a lightweight, fast, and enjoyable terminal experience for Android while learning, experimenting, and building along the way.

🚧 Project Status

Tesminux is currently in early development.

Things may change frequently, features may be incomplete, and bugs are expected.

This project is being developed as a vibe coding project — experimenting with ideas, trying things out, and seeing where the project goes.

✨ Goals
🦀 Build the core with Rust
📱 Make it work well on Android
⚡ Keep it lightweight and responsive
💻 Provide a useful terminal experience
🧪 Experiment with different terminal features
📚 Learn more about Rust, Android, and terminal development
🛠️ Tech Stack
Rust — Core application
Android — Target platform
Cargo — Rust build system and package manager
📦 Installation

Installation instructions will be added as Tesminux becomes more complete.

For now, Tesminux is mainly intended for development and experimentation.

🚀 Development

Clone the repository:

git clone https://github.com/YOUR_USERNAME/Tesminux.git
cd Tesminux

Build the Rust project:

cargo build

Run it:

cargo run

Android-specific build instructions will be added later.
